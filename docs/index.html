How it works

One app on the TV. One integration in Home Assistant.

The app reads what's playing and exposes it — with native control — over a local API. Home Assistant finds the TV on your network, you pair with a code, and every box becomes a proper device.

1

Install the app on the TV

Grant three normal Android permissions: notification access (now-playing), TV info (Watch Next) and accessibility (remote keys). No developer options, no ADB keys, no root.

2

Pair with a code

Home Assistant discovers the TV over mDNS. Enter the 6-digit code — or scan the QR — shown on screen. The TV's certificate fingerprint is pinned from that moment on.

3

Automate

Each TV is a device with a media_player, a remote and sensors. State is pushed the moment it changes. Add the bundled TV frame card and you're done.

Features

Everything a TV should tell your home — and everything it should obey.

What's playing, properly

Title, series and episode, poster, position and duration, playback state and the current app — straight from the Android MediaSession.

The standout

Titles even for apps that hide them

Reads the Android TV Watch Next row to recover show, episode and poster for apps that publish no media metadata at all — TVNZ+ and ThreeNow, for example.

Native control, no ADB

Play / pause / seek and volume through MediaController; D-pad, OK, Back and Home through a tiny accessibility service; app launch and deep links through intents.

Plug-and-play pairing

mDNS discovery, a 6-digit code or QR, and a friendly name. Pair as many TVs as you like — each is its own device in Home Assistant.

Encrypted local API

TLS 1.3 with the TV's certificate fingerprint pinned at pairing, plus a paired token on every request. Nothing leaves your LAN. No cloud, no account, no telemetry.

Sensors and a card, included

Current app, up next, battery, storage, memory, volume, network, IP, Wi-Fi and last boot. Plus the TV frame Lovelace card, registered automatically.

In practice

Pair on the TV, see it in Home Assistant, control it from the card.

Install

Three steps, ten minutes.

  1. The app, on your TV. Install Android TV HA Bridge on the Android TV / Google TV device, open it and follow the on-screen steps. Until the Google Play listing is live, sideload the APK from Releases.
  2. The integration, via HACS. Click the button, or add https://github.com/CyborgFingers/android-tv-ha-bridge as a custom repository (category Integration). Install, then restart Home Assistant. Manual install: copy custom_components/androidtv_ha_bridge/ into your config/custom_components/.
  3. Pair. Home Assistant discovers the TV → Configure → enter the 6-digit code → name it. Repeat for every TV.
PermissionWhy
Notification accessRead the active MediaSession — what's playing
TV info (READ_TV_LISTINGS)Read the Watch Next row
AccessibilitySend D-pad / OK / Back / Home. Reads nothing from the screen
For developers

The data is exposed generically.

A Home Assistant event you can subscribe to from another integration, plus a small documented local API — /api/info, /api/pair, /api/state, /api/command, /api/apps and a WebSocket that pushes the full state document. Nothing is locked to the bundled card.
